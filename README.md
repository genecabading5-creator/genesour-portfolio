# Gocotano Gene C. — Student Portfolio

This starter portfolio is split into separate pages:
- `index.html` — Home (personal introduction)
- `about.html` — About
- `skills.html` — Skills
- `projects.html` — Projects and reflection
- `contact.html` — Contact
- `style.css` — shared responsive design
- `script.js` — mobile navigation behavior

## Preview in VS Code
Open this folder in VS Code, then open `index.html` in a browser (or use a local preview extension). Test every navigation link and the mobile menu.

## Before publishing
Personalize your introduction, About details, skills, project role/findings, reflection, and contact link. Replace the profile placeholder with your own appropriate image if you wish. Do not publish private information. Ensure all project claims reflect your real work.

## GitHub Pages
Upload the contents of this folder to the root of a public repository. Ensure `index.html` is in the repository root. In repository Settings → Pages, choose deployment from branch `main` and folder `/(root)`. After deployment, test the public HTTPS link and all five pages.
